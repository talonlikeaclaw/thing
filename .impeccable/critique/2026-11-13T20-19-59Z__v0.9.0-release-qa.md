# v0.9.0 release QA — numbers that read

Run on 2026-11-13 in headless Chromium against the release build (`web/dist` served by
`thing-server`) over a temporary data directory, never the owner's `./data`. Every number below was
measured in the page after the app settled; screenshots were inspected for composition and are not
stored, as in the previous sheets.

**Release:** `Cargo.toml`, `Cargo.lock` and `web/package.json` read `0.9.0`; the footer reads
`v0.9.0`; the changelog's top entry is `0.9.0` “Numbers that read” dated `2026-11-13` with neither
`Unreleased` nor `upcoming`; `FORMAT_VERSION` is `8`.

## Fixture

A temporary server on port 8090 (`THING_DATA_DIR=/tmp/thing-qa-090`) with the built SPA and one
fresh Garden seed run: relative dates, `America/Toronto`, four Plant records and five Plant views.
The seed's Plant type carries the new `price` number property with `display: {currency: USD,
decimals: 2}`, and the default `All` table view carries `footer_hidden: [nursery]` plus
`footer_summary: {price: sum, days_since_watered: sum, due_date: earliest}` so the band's short text
fits the phone's 104 px compact column. The Nursery text column was given `display: {align: right}`
through the property API for the aligned-text check only; the seed does not store that alignment.

## Method

- Widths `390 × 844`, `768 × 900`, `1024 × 1000`, `1440 × 1000`; `prefers-color-scheme` dark and
  light.
- The 390 state is a narrow desktop viewport with a fine pointer, not a touch device. No coarse
  pointer or physical touch device was attached, and no touch claim is made.
- Overflow is `documentElement.scrollWidth - innerWidth`. A footer cell is counted as truncated
  when its inner `span` reports `scrollWidth > clientWidth`; the full sentence stays in the cell's
  `aria-label` and `title`.
- Surfaces: the Plant ledger with the band on, the band with the Nursery cell blanked, the band
  switched off, the price column scrolled into view on the narrow viewport, the 0.9.0 changelog,
  a keyboard walk and a reduced-motion state.

## Behavior measured

| Check | Result |
|---|---|
| Currency cell | `US$32.00` in the Price cell at every width; the runtime's own `Intl` spelling of USD, not a hand-built string |
| Currency footer | `Σ US$81.25` in the Price cell and right-aligned under its digits; `aria-label` reads `Price: 4 of 4 filled; sum US$81.25` |
| Number alignment | every number cell reports `text-align: right`; the Price cell's text is `59 px` inside `59 px` at 390 and 1440, so the prefix never truncates |
| Text alignment | Room stays `left`; Nursery reports `right` after its `display.align` was set, and its footer cell follows |
| Hidden column | the Nursery footer cell is present, blank and has no `aria-label`; its neighbours keep their totals |
| Band off | no `<tfoot>` and no `Summaries cover all 4 rows.` line at 390 and 1440 in both schemes; the state survives a reload and is written as `footer: false` in the type file |
| Footer fit | no footer cell's inner span is truncated at any width; the narrow viewport's 104 px compact column fits `Σ US$81.25` (`96 px` inside `96 px`) |
| Narrow scroll | at 390 the Price column starts beyond the scrollport; after a sideways scroll it is fully visible (`180–284 px`), cell and footer both inside the viewport, overflow `0` |
| Keyboard | `Tab` moved from the Room cell to `US$32.00`; the active cell carried the 2 px inset accent ring; `Shift+ArrowRight` then `Shift+ArrowDown` selected `2 rows by 2 columns, 4 cells`; `Escape` cleared it |
| Reduced motion | with `prefers-reduced-motion: reduce`, the active cell reported `0s` transition and `0s` animation |
| Changelog | top entry `0.9.0 Numbers that read`, date `2026-11-13`, sections `Say what the number is`, `Line up`, `The band, on your terms` and `Set it where you work`; `Unreleased` absent |

## Decisions taken

- **`US$` is the runtime's USD spelling, not a defect.** `Intl.NumberFormat(undefined,
  {style: "currency", currency: "USD"})` prints `US$32.00` in this headless Chromium's default
  locale. The module deliberately takes the reader's locale, so the sheet records the runtime's
  text rather than pinning `$`.
- **The seed chooses one measure per column where the default line would not fit.** The band's
  short text is a single line; `Σ US$81.25 · avg US$20.31` is wider than the phone's 104 px compact
  column. `price` and `days_since_watered` print their sum, and `due_date` its earliest day, so the
  demo shows the per-column measure and the band never ellipsizes at 390.
- **The 390 ledger starts with the Price column partly beyond the scrollport.** That is the phone
  table's horizontal scroller, not cell clipping: the hint says `Swipe for columns`, and after the
  scroll the cell and its footer are fully inside the viewport.
- **The aligned text column is a QA-only write.** Nursery's `align: right` was PATCHed through the
  property API to prove the pinned edge; the seed keeps its default left edge.
- **No physical touch device.** The 390 state is a narrow viewport with a fine pointer; the
  physical-iPhone gate remains open and this sheet does not close it.
