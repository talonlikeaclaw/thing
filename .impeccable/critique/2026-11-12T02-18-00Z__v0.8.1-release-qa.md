# v0.8.1 release QA — a grid you can work in

Run on 2026-11-11 in headless Chromium against the release build (`web/dist` served by
`thing-server`) over a temporary data directory, never the owner's `./data`. Every number below was
measured in the page after the app settled; screenshots were inspected for composition and are not
stored, as in the previous sheets.

**Release:** the workspace, `Cargo.lock` and `web/package.json` read `0.8.1`; `GET /api/health`
reports `{"version":"0.8.1"}`; the footer reads `v0.8.1`; the changelog's top entry is `0.8.1`
“A grid you can work in” with neither `Unreleased` nor `upcoming`; `FORMAT_VERSION` stays `7`.

## Fixture

A temporary server on port 8090 (`THING_DATA_DIR=/tmp/thing-qa-081`) with the built SPA and one
fresh Garden seed run: relative dates, `America/Toronto`, ten view columns plus Title, four Plant
records and five Plant views. No seed file changed for this release.

## Method

- Widths `390 × 844`, `768 × 900`, `1024 × 1000`, `1440 × 1000`; `prefers-color-scheme` dark and
  light.
- The phone cell uses Puppeteer's `iPhone 13` profile plus `Emulation.setTouchEmulationEnabled`;
  `matchMedia('(pointer: coarse)')` was asserted `true` beside every coarse measurement. The phone
  table was driven with a real `page.touchscreen.tap`, not a mouse event.
- Surfaces: the Plant ledger, a 2 × 2 cell range, the selection bar, the summary footer and its
  scope line, the `?` shortcut sheet, an open select-cell editor, and the 0.8.1 changelog.
- Overflow is `documentElement.scrollWidth - innerWidth`; a footer cell is clipped when
  `scrollWidth > clientWidth`; a coarse target is under the floor when its rendered height is below
  44 px.

## Decisions taken

- **Native `Tab` at the last data cell lands on the row's action rail.** Locked decision 3 keeps the
  rail's tab stops, so the browser's own order reaches it before leaving the card; the grid itself
  does not intercept the key. The test names the contract "leaves the grid", which is what happens.
- **The footer's short text may truncate on a narrow column.** The full sentence stays in the
  cell's `title` and `aria-label`, as the plan requires, so a truncated `Σ 19 · avg 4.…` never hides
  the count.
- **A pointer-initiated clipboard write is refused in headless Chromium.** The keyboard copy landed
  in the real clipboard; for the bar buttons the payload and toast were verified by stubbing
  `navigator.clipboard.writeText` in the page, and the refusal path itself toasted
  `The browser refused the copy.` without throwing.

## Deliberately unchanged

The phone compact table keeps its old row layout and its width budget; the footer joins it as the
table's last row rather than becoming a second phone-only surface. The query toolbar, paging, bulk
bar, column resizing, cell editing and the action rail are untouched. The summary band is read-only
and ephemeral: no view, type, URL or server payload grew a total.

## Limits

No physical device is attached; phone QA is emulation plus measured DOM, and the v0.4.3
physical-iPhone gate remains open. The phone clipboard was not exercised, because the checkpoint
adds no touch copy gesture.
