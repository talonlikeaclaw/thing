# v0.7.1 release QA — workspace craft

Run on 2026-11-10 in headless Chromium against the release build (`web/dist` served by
`thing-server`) over temporary data directories, never the owner's `./data`. Every number below was
measured in the page after the app settled; screenshots were inspected for composition and are not
stored, as in the previous sheets.

**Release:** the workspace and `web/package.json` read `0.7.1`; `GET /api/health` reports
`{"version":"0.7.1"}`; the footer reads `v0.7.1`; the changelog's top entry is `0.7.1` “Workspace
craft” with neither `Unreleased` nor `upcoming`; `FORMAT_VERSION` stays `6`.

## Fixture

A temporary server on port 18095 with the built SPA and two fresh Garden seed runs (relative dates,
`America/Toronto`, four shared properties, eight records, five Plant views). `Nursery` is the
promotion fixture: 4 records, 2 distinct values, 1 empty, 3 links, a column move in `All`, and in
`Nurseries` one sort, one moved `is_not_empty` filter and one dropped value filter. `Room` is shared
by Plant and Chore, so it plans as blocked. One disposable space was promoted through the UI; the
other stayed un-promoted for measurement. Neither is the owner's data.

## Method

- Widths `390 × 844`, `768 × 900`, `1024 × 900`, `1440 × 1000`; `prefers-color-scheme` dark and
  light.
- Coarse pointer by CDP `Emulation.setTouchEmulationEnabled` held open for the whole measurement
  cell, with `matchMedia('(pointer: coarse)')` asserted true beside it. A separate tab without touch
  emulation measured the fine-pointer popovers.
- Surfaces: the Plant ledger and its filter/sort/columns; the phone View sheet; the property picker;
  the record page, add-property sheet and property editor; the schema Types/Properties tabs; the
  command palette's property result; the promotion wizard (Target and Preview); the Columns row menu.
- Overflow is `documentElement.scrollWidth - innerWidth`. Target size is the rendered
  `getBoundingClientRect().height`; the floor is 44 px on a coarse pointer.
- Focus return was checked by focusing the trigger, opening, pressing Escape and reading
  `document.activeElement`.

## Fixes landed by this pass

- **The phone had five toolbar controls, not three.** Sort and Columns were still pushed as toolbar
  squares next to Filter and More; the checkpoint-3 View sheet had never received their bodies.
  `ViewSheet` now carries Sort and Columns rows with counts and bodies, and the compact toolbar
  pushes neither, leaving Search, Filter and View. `DESIGN.md`, `README.md` and the changelog now
  describe the surface that exists.
- `property-picker.tsx` and the manage-properties search gained the `max-sm` 16 px / 44 px floor
  the other search fields already had, so a narrow fine-pointer window matches the phone.

## Known limitation

Emulation only; no physical iPhone is attached, so the v0.4.3 physical-device keyboard gate remains
open. The filter popover's glass is translucent by design (62% fill with an 18 px blur); its own
labels meet contrast, while the ledger behind it remains faintly visible as Night Glass intends.
