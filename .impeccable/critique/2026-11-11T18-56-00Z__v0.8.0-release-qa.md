# v0.8.0 release QA — calculated columns

Run on 2026-11-11 in headless Chromium against the release build (`web/dist` served by
`thing-server`) over a temporary data directory, never the owner's `./data`. Every number below was
measured in the page after the app settled; screenshots were inspected for composition and are not
stored, as in the previous sheets.

**Release:** the workspace and `web/package.json` read `0.8.0`; `GET /api/health` reports
`{"version":"0.8.0"}`; the footer reads `v0.8.0`; the changelog's top entry is `0.8.0` “Calculated
columns” with neither `Unreleased` nor `upcoming`; `FORMAT_VERSION` is `7`.

## Fixture

A temporary server on port 8090 (`THING_DATA_DIR=/tmp/thing-qa`) with the built SPA and one fresh
Garden seed run: relative dates, `America/Toronto`, seven shared properties (three calculated),
eight records, five Plant views. The Plant table carries `days_since_watered` (formula number),
`related_plants` (rollup count) and `related_titles` (rollup list); a fourth formula column,
`room + " / " + nursery`, was created through the table's Add property sheet during the run.

## Method

- Widths `390 × 844`, `768 × 900`, `1024 × 1000`, `1440 × 1000`; `prefers-color-scheme` dark and
  light.
- Coarse pointer by CDP `Emulation.setTouchEmulationEnabled` plus a mobile metrics override, held
  for the measurement cell, with `matchMedia('(pointer: coarse)')` asserted true beside it.
- Surfaces: the Plant ledger, the record page, the schema Properties list and the computed
  property editor, the Add property sheet (Stored / Formula / Rollup and Formula help), the filter
  panel with a list-column condition, the sort header, the phone View and Sort sheets, the Data —
  CSV panel, and the changelog.
- Overflow is `documentElement.scrollWidth - innerWidth`; target size is the rendered
  `getBoundingClientRect().height` against the 44 px coarse floor; clipped header text is
  `scrollWidth > clientWidth` on the format line.

## Deliberately unchanged

The calculated cell keeps the ledger's type scale and right-aligned numbers; a `list` result stays
one truncated line with the full label in the title rather than a chip row, so a row's height does
not depend on a rollup's target count. The phone header keeps the glyph plus `aria-label` because
the format line is dropped there by the ledger's own rule.

## Limits

No physical device is attached; phone QA is emulation plus measured DOM, and the v0.4.3
physical-iPhone gate remains open. Formula evaluation was exercised over the seeded dates only; the
unit and route suites cover the grammar, aggregates and refusal paths.
